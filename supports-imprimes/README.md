# Supports imprimés

Versions à jour de la carte PDF (A4, 16 pages) et du menu extérieur (640 × 610 mm).
Ils doivent toujours concorder avec l'application (`www/js/menu-data.js`) : prix, textes, visuel.

- La carte PDF ne contient ni vins ni desserts (volontaire).
- Le menu extérieur ne peut pas tout reprendre.

Les scripts de `tools/pdf/` lisent et réécrivent le texte de ces PDF en gardant leurs polices.
