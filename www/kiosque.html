Mode kiosque : la tablette ne montre que le menu

À faire une seule fois par tablette, au tout premier allumage.

Ce que fait le mode kiosque

  • Quand on allume la tablette, le menu s’affiche tout seul, sans écran de verrouillage.
  • Le client ne peut pas sortir du menu : pas de bouton Accueil, pas d’autres applications, pas de paramètres, pas de notifications.
  • Le personnel retrouve toute la tablette avec un geste caché et un code.
  • Le menu continue de se mettre à jour tout seul par le Wi-Fi.
À savoir avant de commencer. Le mode kiosque ne peut s’installer que sur une tablette neuve, jamais configurée, ou réinitialisée (Paramètres → Gestion globale → Réinitialisation → Réinitialiser toutes les données — tout ce qui est sur la tablette est effacé). Faites d’abord l’essai sur une seule tablette.

Mise en place

  1. Allumez la tablette. Restez sur le tout premier écran (« Bienvenue »), sans toucher « Démarrer ».
  2. Touchez 6 fois de suite une zone vide de cet écran. Un lecteur de QR code s’ouvre (si la tablette demande d’abord le Wi-Fi, connectez-la).
  3. Scannez le QR code ci-dessous, affiché sur un téléphone ou un ordinateur.
  4. Connectez la tablette au Wi-Fi du restaurant quand elle le demande, puis acceptez les écrans suivants. Elle indique qu’elle est « gérée » ou qu’elle « appartient à votre organisation » : c’est normal, c’est ce qui permet le verrouillage.
  5. Passez les étapes facultatives (compte Google, compte Samsung…).
  6. Le menu s’affiche et vous demande de choisir un code administrateur (4 à 8 chiffres). Notez-le.

Ce QR code ne se scanne que depuis l’écran « Bienvenue » d’une tablette. Il ne contient aucun mot de passe.

Au quotidien

  1. Accéder à la tablette (personnel) : touchez 5 fois rapidement le coin en haut à droite de l’écran, saisissez le code, puis « Déverrouiller ». L’écran d’accueil Samsung habituel revient.
  2. Revenir au menu verrouillé : ouvrez l’application Jalmogoyo Menu. La tablette est de nouveau bloquée sur le menu.
  3. Changer le code : même geste, saisissez le code actuel, puis « Changer le code ».
  4. Éteindre la tablette : appui long sur la touche latérale (ou touche latérale + volume bas), puis « Éteindre ».
Code oublié ? Il n’existe pas de code de secours. Il faut réinitialiser la tablette depuis le mode de récupération Samsung (tablette éteinte : touches volume haut + latérale), puis refaire la mise en place.
Retirer le mode kiosque : déverrouillez la tablette avec le code, puis réinitialisez-la depuis les paramètres.

Sans réinitialiser la tablette : la solution simple

Si la tablette est déjà configurée et que vous ne voulez pas l’effacer, installez l’application normalement, puis utilisez la fonction Samsung d’épinglage :

  1. Définissez un code PIN de verrouillage d’écran sur la tablette.
  2. Dans les paramètres, cherchez « Épingler », activez l’épinglage des applications et l’option qui demande le code PIN pour désépingler.
  3. Ouvrez Jalmogoyo Menu, affichez les applications récentes, touchez l’icône de l’application, puis « Épingler ».
Avec cette solution, le client ne peut pas quitter le menu sans le code PIN. En revanche, après chaque redémarrage, il faut saisir le PIN, rouvrir le menu et l’épingler de nouveau : rien n’est automatique.
