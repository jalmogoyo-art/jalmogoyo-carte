Installer le menu sur une tablette

À faire une seule fois par tablette. Ensuite, le menu se met à jour tout seul.

Télécharger l’application

Sur chaque tablette

  1. Connectez la tablette au Wi-Fi du restaurant.
  2. Ouvrez cette page sur la tablette (QR code ci-dessous) et touchez Télécharger l’application.
  3. Ouvrez le fichier téléchargé jalmogoyo-menu.apk. Si la tablette le demande, autorisez l’installation depuis le navigateur, puis touchez Installer.
  4. Lancez Jalmogoyo Menu. C’est terminé.
Une ancienne version est déjà installée ? Désinstallez-la d’abord (appui long sur l’icône → Désinstaller), sinon la tablette refusera la nouvelle. Ce n’est nécessaire qu’une fois.

Ouvrir cette page sur une tablette

Affichez cette page sur votre téléphone ou votre ordinateur, puis scannez ce QR code avec l’appareil photo de chaque tablette.
Ou tapez l’adresse : jalmogoyo-art.github.io/jalmogoyo-carte/install.html

Mises à jour

Les prix, les plats et les photos se mettent à jour automatiquement sur toutes les tablettes connectées au Wi-Fi, quelques minutes après la modification, quand l’écran d’accueil est affiché. Sans Wi-Fi, la tablette continue d’afficher la dernière version reçue.

Pour vérifier la version d’une tablette : tout en bas du menu, sous « Infos », un numéro comme v123 est affiché. Il doit être le même que celui indiqué sous le bouton rouge de cette page.

Conseils pour le service

Bloquer la tablette sur le menu : dans les paramètres Samsung, cherchez « Épingler les applications », activez l’option, puis épinglez Jalmogoyo Menu depuis la liste des applications récentes. Les clients ne peuvent alors plus quitter le menu.
Voir le menu sans rien installer : ouvrir la version en ligne.
